# 🚀 PortfolioGenie

**PortfolioGenie** is a smart portfolio builder that creates a professional personal portfolio website for you automatically, powered by GitHub integration and AI tools.

## 📖 Overview

Instead of building a portfolio from scratch, 
PortfolioGenie connects to your GitHub account, fetches your projects, and displays them in a clean, ready-to-use portfolio website. 
AI tools help you fill in your information, so you spend less time writing and more time showcasing your work.

## ✨ Features

- 🐙 **GitHub Integration:** Connects to your GitHub account and automatically fetches your repositories to display them as portfolio projects.
- 🤖 **AI-Powered Auto-Complete:** Built-in AI tools that complete your input automatically, such as project descriptions and bio details.
- 💡 **How It Works Section:** A dedicated section that explains how the platform works and walks users through its features.
- 📬 **Contact Us:** A form where users can send feedback or report any problem they face while using the website.
- 👥 **About Us:** A section introducing the project and the team behind it.

## 🛠️ Tech Stack

- ⚛️ React

- 🎨 Bootstrap

## 🏁 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your computer.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/salsabila-adel/DEPI_GP_Portfolio_Builder.git
   ```

2. Move into the project folder:

   ```bash
   cd DEPI_GP_Portfolio_Builder
   ```

3. Install all the required dependencies (React, Bootstrap, and the rest of the libraries):

   ```bash
   npm install
   ```

4. Run the project locally on your desktop:

   ```bash
   npm run dev
   ```

5. Open the link shown in the terminal in your browser (usually `http://localhost:5173`).

## 📌 How to Use

1. Download the project files and install the dependencies as shown above.
2. Run the project locally on your desktop.
3. Connect your GitHub account to import your projects.
4. Use the AI tools to complete your profile and generate your portfolio.
